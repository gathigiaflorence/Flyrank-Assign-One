# My Capstone Project Rules

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Version Control: Git & GitHub

## Formatting & Code Rules
- Keep code simple, clean, and well-commented for a beginner.
- Use modern ES6+ JavaScript syntax.
- Follow Conventional Commits format for Git messages (e.g., feat:, docs:, fix:).

## Project Rules Learned
- Build forms with semantic HTML and accessible labels using matching id and for attributes.
- Validate user input in JavaScript before allowing form submission or saving data.
- Use modular JavaScript and test-driven validation so behavior can be verified with Vitest/JSDOM.
- Prefer inline validation messages that appear near the relevant field for better user feedback.
- Save valid form data to localStorage only after all checks pass.
